# 🔐 Password Strength Checker (Python + Tkinter)

## 📌 Description
A GUI-based application that checks the strength of a password using multiple validation rules.  
It provides real-time feedback to help users create secure passwords.

---

## 🚀 Features
- ✔ Checks minimum password length  
- ✔ Validates uppercase & lowercase characters  
- ✔ Detects numbers and special characters  
- ✔ Displays password strength (Weak / Strong)  
- ✔ User-friendly GUI using Tkinter  

---

## 🛠️ Technologies Used
- Python  
- Tkinter (GUI)  
- Regular Expressions (`re`)  

---

## ▶️ How to Run

1. Install Python  
2. Open terminal in project folder  
3. Run:
